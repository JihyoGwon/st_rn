## 구현 전략: 플랫폼 접근법

### 개념
나는 **"코칭 플랫폼"**을 만들고, 실제 코칭 로직은 **LLM + 프롬프트**로 구현함.

### 역할 분담

#### 내 역할 (AI 개발자)
1. **플랫폼 구축**
   - 데이터 구조 설계
   - API 구현
   - UI 프레임워크 제공

2. **프레임워크 제공**
   - 도메인별 프롬프트 템플릿 구조
   - 평가 메커니즘
   - 목표 추적 시스템

3. **기본 프롬프트 제공**
   - 범용적인 코칭 프롬프트
   - 기본 평가 질문
   - 일반적인 코칭 스타일

#### 사용자/전문가 역할
1. **프롬프트 커스터마이징**
   - 도메인별 전문 프롬프트 작성
   - 평가 질문 커스터마이징
   - 코칭 스타일 조정

2. **캐릭터 설정**
   - 코치 캐릭터의 personality, scenario 설정
   - 도메인별 코치 캐릭터 생성

## 실제 구현 예시

### 예시 1: 평가 시스템

#### 내가 구현하는 것
```javascript
// 평가 엔진 구조
class AssessmentEngine {
  async performAssessment(type, questions, context) {
    // 1. 평가 프롬프트 생성
    const prompt = this.buildAssessmentPrompt(type, questions, context);
    
    // 2. LLM 호출
    const response = await callLLM(prompt);
    
    // 3. 결과 파싱 및 저장
    const results = this.parseResults(response);
    return results;
  }
  
  buildAssessmentPrompt(type, questions, context) {
    // 도메인별 프롬프트 템플릿 사용
    const template = this.getTemplate(type);
    return template.replace('{{questions}}', questions)
                   .replace('{{context}}', context);
  }
}
```

#### 사용자가 제공하는 것
```javascript

// 목표 추적 시스템
class GoalTracker {
  calculateProgress(goal) {
    // 진행률 계산 로직
    const completedMilestones = goal.milestones.filter(m => m.completed).length;
    return (completedMilestones / goal.milestones.length) * 100;
  }
  
  async detectGoalFromMessage(message, context) {
    // LLM을 사용하여 목표 감지
    const prompt = `다음 메시지에서 목표를 추출하세요: ${message}`;
    const goal = await callLLM(prompt);
    return this.parseGoal(goal);
  }
}
```
