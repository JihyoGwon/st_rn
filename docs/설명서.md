# SillyTaver 설명서

## 월드인포/로어북

### 그룹 및 Inclusion
**목표**: 옵션과 우선순위에 따라 어떤 월드인포/로어북을 프롬프트에 주입할 것인지 결정하는 로직
**상세설명**: 
- 적용 우선순위: Group Scoring > Group Override (Prioritize) > Group Weight
    - Group Scoring: 더 많이 언급된 키워드가 들어있는 로어북을 적용
        에시: 로어북1(미래, 세상), 로어북2(꿈)일 때, 사용자가 '미래세상에 대한 꿈을 꿨어' -> 로어북1=2, 로어북2=1 -> 로어북1선택
    - Group Override: Prioritize가 체크되어 있는 로어북을 적용
    - Group Weight: 가중치에 따라 랜덤하게 적용

### Sticky/Cooldown/Delay
**Sticky**: 엔트리가 활성화되면 n개 메시지 동안 계속 활성화됨
    - 같은 그룹에서는 Sticky 엔트리가 우선됨 (1번엔트리가 sticky에 의해 활성화 중일때는 그 외 엔트리는 활성화되지 않음)
    - 다른 그룹이면 각각 독립적으로 활성화됨
**Cooldown**: 엔트리가 활성화되면 n개 메시지 동안 활성화되지 않음
**Delay**: 채팅이 n개 미만일때는 활성화되지 않음

### Decorators
- 엔트리 콘텐츠에 다음을 표시
    - @@activate -> 강제 활성화
    - @@dont_activate -> 강제 비활성화
    - **추후 동적 프롬프트 구현시 고려해볼만한 기능!**

### 재귀 스캔
- 예시
    엔트리a
    - 키워드: 마법
    - 콘텐츠: 마법사는 지팡이를 사용한다. 마법사는 어제 지팡이를 분실했다.

    엔트리b
    - 키워드: 마법 지팡이
    - 콘텐츠: 지팡이의 주문은 '수리수리 마수리'이다.

    엔트리c
    - 키워드: 분실
    - 콘텐츠: 마법사의 분실된 물건은 산기슭 또는 호수에 버려져있다.
    -----
    사용자: 안녕 나는 꼬마마법사 레미야.
    -----
    다른 별도의 옵션은 설정하지 않고 월드 인포의 재귀 스캔을 허용한 경우,
    [1] 엔트리a 키워드 매칭 '마법'
    [2-1] 재귀스캔에 의해 엔트리b 키워드 '마법 지팡이'를 엔트리a 콘텐츠에서 검색. '마법 지팡이'가 없으므로 프롬프트 주입x
    [2-2] 재귀스캔에 의해 엔트리c 키워드 '분실'을 엔트리a 콘텐츠에서 검색. '분실'이 있으므로 프롬프트 주입o
    [3] 결론: 엔트리 a, c가 프롬프트에 주입됨

**non-recursive**: 일반 스캔은 활성화되나 재귀 스캔에서 제외됨
    - 위 사례에서 엔트리c에 non-recursive를 걸었을 경우, 엔트리a가 활성화 되었을 때 [2-2]가 작동하지 않음. 즉 엔트리a의 프롬프트만 주입되고 끝남
**추가 재귀 방지**: 해당 엔트리는 다른 엔트리를 재귀 스캔 할 수 없음
    - 위 사례에서 엔트리a에 추가 재귀 방지를 걸었을 경우, 엔트리a가 활성화 되었을 때 재귀 스캔은 발생하지 않음. 즉 엔트리a의 프롬프트만 주입되고 끝남
**재귀까지 지연**: 일반 스캔은 허용하지 않고 재귀 스캔에서만 활용됨
    - 위 사례에서 엔트리a에 재귀까지 지연을 걸었을 경우, 엔트리a는 활성화되지 못함(키워드 매칭을 할 수 없으므로). 재귀 스캔이 발생하려면 다른 엔트리가 먼저 활성화되어야 하는데 이 경우 활성화된 엔트리가 없으므로 모든 엔트리가 비활성화 됨.
    - recursion level: 몇 번째 재귀 스캔에서 활성화 할 것인지?
