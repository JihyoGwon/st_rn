# SillyTaver 설명서

## 월드인포/로어북

### 그룹 및 Inclusion
**목표**: 옵션과 우선순위에 따라 어떤 월드인포/로어북을 프롬프트에 주입할 것인지 결정하는 로직
**상세설명**: 
- 적용 우선순위: Group Scoring > Group Override (Prioritize) > Group Weight
    - Group Scoring: 더 많이 언급된 키워드가 들어있는 로어북을 적용
        에시: 로어북1(미래, 세상), 로어북2(꿈)일 때, 사용자가 '미래세상에 대한 꿈을 꿨어' -> 로어북1=2, 로어북2=1 -> 로어북1선택
    - Group Override: Prioritize가 체크되어 있는 로어북을 적용
    - Group Weight: 가중치에 따라 랜덤하게 적용

### Sticky/Cooldown/Delay
**Sticky**: 엔트리가 활성화되면 n개 메시지 동안 계속 활성화됨
    - 같은 그룹에서는 Sticky 엔트리가 우선됨 (1번엔트리가 sticky에 의해 활성화 중일때는 그 외 엔트리는 활성화되지 않음)
    - 다른 그룹이면 각각 독립적으로 활성화됨
**Cooldown**: 엔트리가 활성화되면 n개 메시지 동안 활성화되지 않음
**Delay**: 채팅이 n개 미만일때는 활성화되지 않음

### Decorators
- 엔트리 콘텐츠에 다음을 표시
    - @@activate -> 강제 활성화
    - @@dont_activate -> 강제 비활성화
    - **추후 동적 프롬프트 구현시 고려해볼만한 기능!**
